## 1. Overview

Lakoff & N\'{u}\~{n}ez's *Where Mathematics Comes From* [@lakoff2000where] provides the foundational cognitive-scientific framework for Project NUMERATA. Their central claim — that mathematics is built from embodied conceptual metaphors grounded in bodily experience — transforms our investigation from "which numeral system is better?" to "which embodied experiences does each system recruit, and what does that enable or foreclose?"

This document maps Lakoff & N\'{u}\~{n}ez's four grounding metaphors onto the major numeral systems under investigation and derives the "metaphor recruitment profile" for each system. This profile becomes a key evaluative dimension in our numeral taxonomy.

---

## 2. The Four Grounding Metaphors

Lakoff & N\'{u}\~{n}ez identify four primary metaphors through which embodied experience is mapped onto arithmetic:

### 2.1 Arithmetic Is Object Collection

| Component | Mapping |
|-----------|---------|
| **Source domain** | Collecting objects into groups |
| **Numbers** | Groups of objects (of the same size) |
| **Addition** | Putting groups together |
| **Subtraction** | Taking objects away from a group |
| **Zero** | The empty collection |
| **Equality** | Same number of objects |
| **Bodily basis** | Manipulating physical objects, subitizing small collections |

**Natural numeral systems:** Tally marks (`IIII`), early Roman numerals (`III`, `VII`), any system where numbers are visibly composed of unit marks. These systems make the collection metaphor explicit: each mark is an object, and the numeral string is the collection.

### 2.2 Arithmetic Is Object Construction

| Component | Mapping |
|-----------|---------|
| **Source domain** | Constructing objects from parts |
| **Numbers** | Physical segments (wholes composed of parts) |
| **Addition** | Putting segments together end-to-end |
| **Subtraction** | Removing a segment from a whole |
| **Zero** | Zero-length segment |
| **Bodily basis** | Spatial reasoning, measuring, building |

**Natural numeral systems:** Measurement-based systems, the number line (as a spatial construct), length-based representations. Positional systems in their spatial aspect recruit construction metaphors.

### 2.3 Arithmetic Is Motion Along a Path

| Component | Mapping |
|-----------|---------|
| **Source domain** | Physical motion along a trajectory |
| **Numbers** | Locations on a path |
| **Addition** | Moving forward along the path |
| **Subtraction** | Moving backward along the path |
| **Zero** | The origin point |
| **Bodily basis** | Locomotion, reaching, pointing |

**Natural numeral systems:** The mental number line (SNARC effect), counting as traversal, ordinal representations. This is the dominant embodied metaphor for the Western number line.

### 2.4 The Measuring Stick Metaphor

| Component | Mapping |
|-----------|---------|
| **Source domain** | Physical measurement with a stick |
| **Numbers** | Marked segments on a measuring stick |
| **Addition** | Extending the stick |
| **Subtraction** | Shortening the stick |
| **Zero** | No length |
| **Bodily basis** | Using tools, comparing lengths, physical measurement |

## 3. Metaphor Recruitment Profiles

For each major numeral system class, we map which embodied metaphors are primed:

| System Class | Collection | Construction | Motion | Measuring |
|--------------|------------|-------------|--------|-----------|
| Tally marks | **PRIMARY** | Weak | Minimal | Weak |
| Roman numerals | **PRIMARY** | Moderate | Minimal | Weak |
| Hindu-Arabic (positional) | Weak | Strong | **PRIMARY** | **PRIMARY** |
| Mayan (vigesimal positional) | Weak | Strong | **PRIMARY** | Strong |
| Binary | Minimal | Strong | Moderate | Weak |
| Signed-digit (balanced) | Minimal | Strong | Strong | Moderate |
| Cistercian | Minimal | Weak | Minimal | Weak |
| Mixed-radix (time/angle) | Weak | **PRIMARY** | Moderate | Strong |

### 3.1 Analysis

The Hindu-Arabic positional system's dominance in Western education may partially reflect its alignment with the motion-along-a-path metaphor (the number line), which is culturally privileged in Western spatial cognition [@dehaene2008log].

Tally and additive systems (Roman numerals, early counting systems) recruit the object collection metaphor, which aligns with subitizing and object-tracking cognition present from infancy [@carey2009origin].

Systems that recruit multiple metaphors (Hindu-Arabic recruits at least three) may have greater cognitive flexibility but also greater potential for metaphor interference.

## 4. Evaluative Implications

### 4.1 Metaphor Recruitment as an Evaluative Axis

For each numeral system, we ask:
1. Which embodied metaphors does this system recruit?
2. How well does each metaphor map to the system's structure?
3. Are there conflicting metaphors within the same system?
4. What cognitive capabilities are required vs. innate?

### 4.2 Design Implications

A novel numeral system could be designed to:
- **Maximise metaphor alignment:** Choose a primary metaphor and make the notation structurally congruent with it.
- **Maximise metaphor diversity:** Support multiple metaphors to accommodate diverse learners.
- **Minimise metaphor interference:** Avoid structures that activate conflicting metaphors simultaneously.

### 4.3 Falsifiability

This framework makes empirically testable predictions:
- Users of tally-based systems should perform better on collection-based arithmetic tasks.
- Users of positional systems should show stronger SNARC effects (spatial-numerical association).
- Novel systems designed to align with a specific metaphor should show faster learning for users with strong grounding in that metaphor.

These would be disconfirmed if metaphor-consistent design produces no measurable performance advantage over metaphor-inconsistent designs in controlled experiments `[speculative]`.
